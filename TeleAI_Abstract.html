Abstract

TeleAI: A Grounded Edge-Cloud Dual-LLM Architecture for Explainable Telecom Plan Recommendation and Counterfactual Simulation

Selecting an optimal prepaid mobile plan in competitive telecommunication markets is a high-dimensional and non-trivial decision problem. In markets such as India, with over 1.15 billion active wireless connections, major telecom providers—principally Reliance Jio, Bharti Airtel, Vodafone Idea (Vi), and BSNL—offer hundreds of overlapping recharge options featuring heterogeneous pricing, arbitrary validity windows, daily high-speed bandwidth limits, and fragmented Over-The-Top (OTT) entertainment bundles. In practice, finding the best plan that satisfies specific budget, data, and validity needs is tedious and overwhelming for subscribers. Generic conversational AI assistants and Large Language Models (LLMs) are fundamentally unsuitable for direct plan selection: because generative models are prone to hallucination, they routinely fabricate non-existent tariff prices, suggest outdated bundles, or invent incompatible validity periods, directly degrading user trust and causing financial misdirection.

A review of existing work shows that Conversational Recommender Systems (CRSs) facilitate multi-turn preference elicitation (Jannach et al., 2021), that grounding generative models in verified external knowledge prevents factual hallucination (Lewis et al., 2020), that contrastive explanations significantly increase user satisfaction and system transparency (Miller, 2019), and that lightweight quantized models enable efficient edge inference on standard consumer hardware (Meta AI, 2024). However, surveyed telecom recommendation tools published between 2020 and 2024 focus predominantly on static rule-based filters or unconstrained end-to-end LLM chatbots, leaving four critical research gaps: no existing system provides conversational natural-language understanding while strictly preventing generative tariff hallucination; standard chatbots offer arbitrary suggestions without mathematical multi-attribute utility optimization; existing solutions provide black-box recommendations lacking contrastive “Why This / Why Not” justification; and none offer real-time counterfactual simulation allowing users to interactively test sensitivity to parameter changes.

To resolve these challenges, this project presents TeleAI, a grounded dual-LLM architecture that strictly decouples linguistic preference extraction from deterministic catalog evaluation and contrastive explanation generation. User queries entered in natural conversational language are first parsed by an edge-deployed Small Language Model (Llama 3.2 3B served locally via Ollama), which enforces strict JSON grammar to output a validated multi-dimensional preference vector (budget ceiling, daily bandwidth, validity window, OTT requirements, and operator preferences). This vector is ingested by a deterministic Multi-Attribute Utility Theory (MAUT) recommendation engine executing hard constraint boundary invalidation over an indexed catalog of 212 verified plans across Jio, Airtel, Vi, and BSNL. Plans violating hard constraints are eliminated immediately, while eligible candidates are scored via dynamically weighted utility functions across budget fit, bandwidth efficiency, validity alignment, and bonus perks, isolating the mathematically optimal Top-3 candidate plans in under 3 milliseconds.

The system is implemented as a decoupled, modern full-stack web application: a reactive Next.js and TypeScript frontend delivers an intuitive conversational interface alongside an interactive counterfactual “What-If” simulation workbench, while the backend orchestrates the local Llama 3.2 inference runtime, the deterministic MAUT scoring engine, and an asynchronous cloud analyst model (GPT-OSS 20B). Rather than generating recommendations, the cloud model is exclusively tasked with synthesizing structured contrastive explanations that articulate why the Rank-1 plan was chosen over Rank-2 and Rank-3. To guarantee uninterrupted reliability, a built-in deterministic fallback engine synthesizes rule-grounded contrastive rationales directly from utility score deltas whenever cloud connectivity is unavailable or latency exceeds operational thresholds.

Implementation proceeded across four structured phases. The data engineering phase established an indexed catalog schema covering 212 active prepaid recharge plans scraped and verified across all four major Indian operators. The edge vectorization and scoring phase developed the grammar-constrained prompt engineering pipeline for Llama 3.2 alongside the vectorized MAUT scoring algorithms. The application layer phase built the reactive Next.js interface, integrating conversational input, recommendation card rendering, and client-side reactive state management. Finally, the testing and hardening phase validated the architecture across four representative user scenarios—ranging from multi-constraint explicit queries to under-specified and approximate budget requests—benchmarking JSON extraction fidelity, deterministic scoring latency (< 3 ms), in-situ slider sensitivity recalculation (< 15 ms), and zero-hallucination compliance.

The resulting prototype demonstrates that decoupling conversational understanding from factual decision logic eliminates generative tariff hallucinations while maintaining fluid natural language interaction. By grounding recommendations in an auditable catalog and providing contrastive explanations alongside real-time counterfactual exploration, TeleAI empowers subscribers to make informed, mathematically validated telecommunication decisions. Planned extensions include real-time web-scraping pipelines for live tariff synchronization, multilingual speech-to-text querying for regional mobile users, and personalized usage-pattern integration via device telemetry.
